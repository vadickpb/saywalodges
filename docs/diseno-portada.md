# Diseño de la portada (SD-1134)

La portada pública sigue un diseño cálido de lodge: cabecera crema, héroe con foto, barra de disponibilidad, villas y servicios.

## Para activarlo en tu sitio (1 minuto)
Panel → **Sitio → Apariencia** → Preset **«Valle Sagrado»** → Guardar. Eso pone verde bosque (`#1F4031`), terracota (`#A5522D`), crema
(`#F7F2E8`) y tipografía serif (Playfair para títulos, Lora para el texto). Puedes retocar los colores uno a uno después.
La estructura nueva (cabecera, héroe, barra de fechas, tarjetas) ya funciona con cualquier tema; el preset solo da el aspecto.

## De dónde sale cada cosa (nada está escrito a mano en el diseño)
| Lo que ves | Dónde lo cambias |
|---|---|
| Titular grande y lema en cursiva | Sitio → Apariencia → textos: «Titular» y «Lema» |
| Foto de fondo del héroe | Sitio → Fotos → foto principal |
| Foto enmarcada de la derecha | La primera foto de la galería distinta de la principal |
| Leyenda de esa foto («Piscina temperada · Hidromasaje») | El primer «destacado» del sitio (si no hay, no se muestra leyenda) |
| Ubicación bajo el botón | Dirección de la propiedad |
| Tarjetas de las villas, «hasta N huéspedes», habitaciones, precio «desde» | Sitio → Unidades (capacidad, habitaciones, tarifas) |
| Tarjeta «Complejo completo» | Una unidad compuesta de otras (Sitio → Unidades → «Combinada») |
| Franja de 5 servicios con icono | Sitio → Servicios (los 5 primeros) |
| Menú: Inicio, Villas, Experiencias, Galería, Ubicación | Aparecen solo las secciones que existen |

## La barra de disponibilidad
Llegada, salida y huéspedes llevan a **/cotizar** con las fechas ya puestas; allí el huésped elige la unidad y ve el precio exacto. El
servidor vuelve a validar todo (fechas futuras, máximo de noches, capacidad): la barra solo evita escribir las fechas dos veces.

## Qué no cambia
Galería, espacios, tarifas, calendario público, ubicación, preguntas, contacto y el pie de página siguen igual (heredan los colores y las
fuentes del preset). El menú móvil conserva la lista completa de secciones.
